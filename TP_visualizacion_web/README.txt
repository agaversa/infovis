Archivos:
- index.html: pagina principal
- assets/treemap_gastos_categoria.svg: grafico exportado desde RAWGraphs

Publicar en GitHub Pages:
1. Crear un repositorio nuevo en GitHub.
2. Subir index.html y la carpeta assets/ manteniendo esa estructura.
3. Settings > Pages > Build and deployment > Deploy from a branch.
4. Elegir rama main y carpeta / (root); guardar.
5. Esperar a que GitHub muestre el enlace del sitio.

El grafico Flourish se carga desde https://public.flourish.studio/visualisation/30888503/ y requiere conexion a Internet.
No subir CSV de transacciones personales ni los resumenes PDF a un repositorio publico.
